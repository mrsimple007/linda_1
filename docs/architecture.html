Linda Architecture

Personal voice + Telegram assistant · runs on a Mac, talks through the mic, Alisa and Telegram

One command, three ways in

  • • Mac mic: wake word → local Whisper → Brain → spoken reply
  • • Alisa: Yandex hears and speaks; Linda answers in 2.6 s or says it on «ну что»
  • • While Alisa is active, the Mac ears stay off (5 min)
  • • Telegram: same Brain, replies as styled cards

Inside the core

  • • Fast path answers simple commands with no LLM
  • • Brain runs the agent loop; providers rest after errors
  • • Risky actions wait for a spoken confirmation
  • • Agent = 14 core methods + 10 feature mixins

Memory and proactive work

  • • Everything is saved as md files + SQLite in ~/LindaData
  • • Recall finds notes by meaning (bge-m3, any language)
  • • Linda writes first: 09:00 reminders, client follow-ups
  • • Sunday 19:00 weekly review, answered in Telegram
